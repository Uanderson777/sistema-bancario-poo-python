# Sistema Bancário em POO com Python

Projeto desenvolvido durante o bootcamp da DIO para aplicar conceitos de Programação Orientada a Objetos (POO) em Python.

## Funcionalidades
- Cadastro de clientes
- Criação de contas
- Depósitos
- Saques
- Extrato bancário
- Controle de transações

## Tecnologias
- Python 3
- Programação Orientada a Objetos
